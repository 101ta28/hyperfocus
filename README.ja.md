# Hyperfocus

[English](README.md)

Hyperfocus は、学習・開発・執筆など、自分で進めたい作業に取りかかるためのエージェントスキルです。まず試せる小さな課題を示し、結果を一緒に確認しながら、つまずきに合わせて次の一歩を調整します。

応答には利用者の希望する言語を使います。指定がなければ、会話で主に使っている言語に合わせます。

## セッションの進め方

1. 今回の小さな目標、達成を確認する方法、終了の目安を決めます。
2. 問題の一部を解く、小さなサンプルを動かす、一文を書くなど、具体的な作業を一つ試します。
3. 結果を確認し、必要に応じてヒントや修正点、次の課題を受け取ります。
4. 作業に役立つ疑問があれば掘り下げます。自分で結果を確認できる場合は、そのまま作業を続けられます。
5. 決めたところで区切り、再開するときの最初の一歩を残します。

時間を決めていない場合は、まず10分程度のお試しを提案します。これは調整の出発点であり、必ず守る時間割ではありません。時刻に合わせた通知には、実際に設定したタイマーや通知の仕組みが必要です。

## Codex への導入

このリポジトリに含まれるのは指示文とメタデータです。ビルドやアプリケーションの起動は不要です。以下の方法で使うには、ローカルスキルに対応した Codex が必要です。

macOS または Linux でリポジトリをダウンロードするかクローンし、**リポジトリのルートディレクトリで**次のコマンドを実行します。リンク先の `~/.agents/skills/hyperfocus` がまだ存在しないことを確認してください。

```sh
mkdir -p "$HOME/.agents/skills"
ln -s "$PWD" "$HOME/.agents/skills/hyperfocus"
```

これにより、Codex のユーザー用スキルディレクトリから、このリポジトリを参照するリンクを作成します。利用中はリポジトリを移動しないでください。Codex はシンボリックリンク経由のスキル読み込みに対応しています。スキルが表示されない場合は Codex を再起動してください。詳細は[公式のスキルドキュメント](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)を参照してください。

## 使い方

Codex のプロンプトに `$hyperfocus` と書き、取り組みたい作業を伝えます。使える時間や困っていることが分かっていれば、一緒に伝えてください。

**学習**

```text
$hyperfocus 再帰を20分ほど勉強したいのですが、関数の呼び出しを追うと
混乱します。小さな例を一つ試すところから手伝ってください。
```

**開発**

```text
$hyperfocus 失敗しているテストを直したいのに、先延ばしにしています。
最初に確認する箇所を一つ決めて、進み具合を確認するのを手伝ってください。
```

**執筆**

```text
$hyperfocus 記事の導入を書きたいのですが、書き始められません。
伝えたいことを一文にするところから手伝ってください。日本語でお願いします。
```

最初から計画を揃える必要はありません。作業が決まっていなければ、何に取り組みたいかを尋ねるところから始めます。フィードバックは回答・実行結果・下書きなどに基づき、経過時間だけで進んだとは判断しません。

## 対象と制約

このスキルは、利用者自身の試行と判断を支援します。通常の作業を代行するためのスキルでも、医学的な診断のためのスキルでもありません。過集中やフローへの到達を保証せず、両者を同じ意味として扱いません。

作業の成果とともに、疲労や中断のしやすさも重視します。終了したいという意思を尊重し、睡眠や食事を犠牲にすることは勧めません。スキルを呼び出しただけでは、個人の記録の保存や通知設定の変更を許可したことにはなりません。
